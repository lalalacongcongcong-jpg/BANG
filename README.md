# 하루 한 줄 · 우리 교실 웹앱 허브

일기 쓰기 안내와 개인정보를 입력하지 않는 도구를 모은 정적 웹앱입니다.

- 일기 주제 30개와 분류·보조 질문·복사·인쇄
- 일기를 쓰면 좋은 점, 학생·교사용 안내, 5분 쓰기 길잡이
- 1·3·5·10분 타이머
- 기존 일기장·웹앱 링크 연결, 검색, 분류, 즐겨찾기

## 개인정보와 공개 범위

이 저장소와 GitHub Pages 화면은 공개용입니다. 실제 학생 명부·학번·일기·피드백·학교 문서·인증정보를 포함하지 않습니다. 로그인과 서버 데이터베이스가 없고 학생 자료를 제출하는 기능도 없습니다. 개인정보가 필요한 일기장 백엔드로 사용하지 마세요.

직접 등록한 웹앱 이름·주소·분류와 즐겨찾기는 사용 중인 브라우저에만 저장합니다. 다른 사람의 허브 화면에 공유되지 않습니다. 같은 GitHub Pages 도메인의 다른 프로젝트는 브라우저 저장 공간을 공유할 수 있으므로 비밀번호, 비공개 초대 링크, 학생 정보가 들어 있는 주소는 저장하지 마세요. 경로별 저장 키는 이름 충돌 방지용이며 보안 격리는 아닙니다.

기존 Sites에서 연결해 둔 목록은 새 주소로 자동 이전하지 않습니다. 실제 일기장 URL은 아직 제공되지 않아 기본 목록에 임의 주소를 넣지 않았습니다. **내 일기장 연결하기**에서 HTTPS 기본 주소를 등록하세요. 원래 웹앱의 자료와 공개 권한은 변경하지 않습니다.

앱에 광고·행동 분석·외부 API 전송 코드를 넣지 않았습니다. GitHub 등 호스팅 서비스는 서비스 운영에 필요한 접속 정보를 처리할 수 있습니다. [GitHub 개인정보 안내](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)를 참고하세요.

## 개발과 검사

별도 패키지 설치가 필요 없습니다. Node.js 22 이상에서:

```sh
node --check dist/app.js
node --test tests/security.test.cjs
node scripts/preview.cjs
```

브라우저에서 http://127.0.0.1:4318/ 에 접속합니다.

## GitHub Pages 배포

저장소 **Settings → Pages → Build and deployment → Source: GitHub Actions**를 선택합니다. main에 푸시하면 `.github/workflows/pages.yml`이 검사를 실행하고 dist 폴더만 배포합니다. Pages 설정 변경은 저장소 관리 권한이 필요합니다. 이 워크플로에는 별도 개인 액세스 토큰이나 유료 서비스 키가 필요 없습니다.

프로젝트 하위 경로에서 작동하도록 정적 파일 주소는 상대 경로를 사용합니다. 실행 결과는 Actions의 Publish classroom hub에서 확인합니다. 공개 화면에서 잘못된 변경을 발견하면 이전 커밋을 되돌린 새 커밋을 main에 올려 다시 배포하세요.
